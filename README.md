# Molecular Docking and Virtual Screening for Target Inhibition

Author: Syeda Aniqa Bukhari  
Education: Master of Science in Bioinformatics, NUST  

## Project Overview
This repository contains computational drug design and molecular docking workflows for screening small molecule inhibitor candidates against therapeutic target proteins.

## Methodology
1. Target Preparation: PDB structure acquisition, water removal, hydrogen addition, and Gasteiger charges assignment.
2. Grid Box Configuration: Centered on the active catalytic binding pocket coordinates.
3. Virtual Screening and Docking: Molecular docking simulations using AutoDock Vina scoring functions to determine binding free energy.
4. Interaction Analysis: Post docking visualization of hydrogen bonds, hydrophobic interactions, and binding poses.

## Key Findings
Top lead molecule exhibited strong binding affinity of minus 9.4 kcal per mol with stable hydrogen bonds at critical active site residues Asp155, Trp151, and Gly369.

## Applications
Structure based drug discovery, hit to lead optimization, and rational inhibitor design.
